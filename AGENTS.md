# Electron SDK — Agent Instructions

Before making or reviewing changes, read the following:

- `docs/README.md` — documentation index; links to conventions, architecture, testing, and development guides
- `docs/REVIEW.md` — code review guide; what to look for

When implementing, follow `docs/CONVENTIONS.md` and `docs/TESTING.md`, and self-review the diff against
`docs/REVIEW.md` before pushing.
